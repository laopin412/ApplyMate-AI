# v0.1 本機前端 MVP 實作說明

> 日期：2026-11-16。來源：本次「第一階段網頁開發任務」、已提出的開發計畫，及使用者「我想先依照上面的規則建立一個初步的網頁」。

## 本次範圍與決策關係

- 對應 D-03～07、D-17～20、D-26～29、D-34～37：首頁、直接進訪客平台、六項導航、可跳過任務、九類手動表單、草稿與完成度。
- D-10 的本機資料庫延後至後端階段；本次依明確指示只用 LocalStorage。
- D-08、D-23～25、D-30～33、D-38～41 保留完整產品方向，這次不實作會員、提醒、AI 匯入／生成／面試。
- 未開放功能對所有使用者一致，與訪客權限限制無關。

## 工程落地

- React + TypeScript + Vite；React Router 使用 HashRouter，首版不依賴後端。
- Lucide 提供圖示；未使用外部字型／遠端圖片，沒有外部 AI 或個資傳送。
- 原生 CSS 集中在 `src/styles/global.css`，以分類區段、變數與斷點維護。先前提案中的 CSS Modules 未導入，後續可拆分，不影響產品規格。
- `GuestRepository` 透過 `StoragePort` 隔離持久化。UI 經 Store 寫入；未來可導入後端資料存取層，不把頁面綁定資料庫。
- 單一儲存鍵 `applymate.guest.v1`，version=1，包含正式資料、分類草稿、修改歷程及新手任務偏好。寫入成功才更新記憶體正式狀態。
- 寫入前比對載入版本，偵測另一分頁更新時阻止舊資料覆蓋；不是完整交易鎖，不支援協同編輯。
- 格式異常／未知版本阻擋寫入並保留原始資料；容量錯誤不清空資料，表單仍保留本次內容並提醒複製。

## 首版資料欄位

以下為此可逆原型的實作欄位，可依使用者回饋調整，不是正式後端 schema。

| 分類 | 欄位 |
|---|---|
| 基本資料（單份） | 姓名、就讀學校、就讀科系、學歷階段、在學狀態；Email、聯絡電話、關於我 |
| 學歷背景 | 學校、科系、學歷階段、開始／結束年月、說明 |
| 學業表現 | 成績項目、學期／期間、成績值、滿分／計分方式、排名、總人數、說明 |
| 專題與研究 | 名稱、角色、指導老師、開始／結束年月、說明、個人貢獻、成果連結 |
| 競賽與獎項 | 競賽、主辦單位、日期、獎項、個人貢獻 |
| 專業技能 | 名稱、分類、熟悉程度描述、應用經驗 |
| 證照與檢定 | 名稱、發證單位、取得日期、成績／級別、有效期限 |
| 實務經驗 | 單位、職務、類型、開始／結束年月、內容與成果 |
| 其他經歷 | 名稱、類型、角色、開始／結束年月、內容 |

- 基本五欄只決定完成度，不阻擋不完整保存；其他八類多筆且全部選填，但不建立完全空白紀錄。
- 單行最多 1,000 字，多行最多 10,000 字，屬可調整的首版工程限制。
- 非空 Email、HTTP/HTTPS 網址與起訖日期做基本驗證；不自動換算成績或推測資料。
- 最近 20 次正式變更（所有分類合計）含分類操作前快照；復原也記錄新版本。
- 刪除、捨棄草稿、復原經頁內確認視窗；復原清除該分類現有草稿。每類一份草稿，改編輯同類另一筆前先確認。

## 畫面與誠實呈現

- 白色、深藍、局部藍紫漸層；首頁介面示意明確標示，不放使用者個資。
- 申請／文件／面試／錄取統計為「—／尚未開放」。近期事項為空狀態，不捏造日期。
- 新手任務以正式資料判斷；學校與文件任務保留未開放標示。
- 740px 以下採行動選單、分類選擇器與單欄表單，其他斷點見 CSS。
- 納入鍵盤焦點、跳至主要內容、dialog 焦點限制、錯誤與狀態提示；未做完整 WCAG 稽核。
